# Features

## Discover and match

Under **${ui:nav.grid}** you see profiles near you, sorted by rough distance. If you like someone, send a **flame**. If they send one back, it's a **match**. Depending on the other person's settings, you can send only a few messages – or none – before a match.

## Chat

- **Messages** with replies, reactions, search and stars.
- **Images and snaps:** A snap can be viewed once and replayed once, and disappears after a time you choose.
- **Voice messages** up to 15 minutes. The first minute arrives even when the other person is offline; the rest follows over a ${term.directConnection}.
- **Videos** up to 25 MB – only over a ${term.directConnection}, never through the server.
- **Gestures:** swipe a message sideways = reply, double tap = heart, pull the contact bar down = profile.

All content is ${term.encrypted}.

## Friends and status

In chat mode you add contacts. Friends see your full profile and your **status** – a text or photo for 24 hours.

## Albums

You share private albums in a specific chat and can revoke access at any time. The keys expire regularly.

## Events

With an event code (e.g. for a party) you only see, for 12 hours, the people who entered the same code. The server never sees the code in plain text.

## Staying invisible

- **${ui:settings.silentMode}:** You are invisible in the grid; existing chats keep working.
- **${ui:settings.safeZones}:** At saved places (e.g. home) you are invisible automatically.
